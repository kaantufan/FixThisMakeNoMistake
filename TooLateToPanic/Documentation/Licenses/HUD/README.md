# Home V4.6 HUD yazı tipleri

Oswald, Barlow ve Barlow Condensed çevrimdışı Unity Font assetleri olarak Assets/Game/Resources/HUD içinde paketlenir. Google Fonts resmi kaynak deposundan 17 Ekim 2026'da indirildi. Tam SIL Open Font License 1.1 metinleri bu klasörde korunur; internet bağlantısı veya işletim sisteminde font kurulumu gerekmez.

- Oswald: The Oswald Project Authors. [Kaynak](https://github.com/google/fonts/tree/main/ofl/oswald). Değişken TTF, fontTools 4.62.1 ile wght=600 sabit TTF'ye dönüştürüldü; glif çizimleri değiştirilmedi.
- Barlow Regular: The Barlow Project Authors. [Kaynak](https://github.com/google/fonts/tree/main/ofl/barlow). Kaynak statik TTF değiştirilmedi.
- Barlow Condensed SemiBold: The Barlow Project Authors. [Kaynak](https://github.com/google/fonts/tree/main/ofl/barlowcondensed). Kaynak statik TTF değiştirilmedi.

Dosya URL/hash/dönüşüm kaydı: Evidence/GamejamOrchestra/TLTP-HUD-V46-20261017/font-receipt.json. Bu kayıt bir font satın alımı, abonelik veya sağlayıcı kredisi içermez. HTML konsepti ve mevcut oyun ikonları korunur; ekran görüntüsü arka planları oyuna statik sahne olarak alınmaz.
